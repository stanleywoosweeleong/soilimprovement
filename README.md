# 土壤修复 · Soil Recovery

**土壤修复 (Soil Recovery)**, formerly "Huang Soil Atlas", is a single-page reference app on the soil research and field methods of **Dr. Huang Jui-chang (黄瑞彰)**, the "Soil Nutritionist" at Taiwan's Tainan District Agricultural Research and Extension Station (Tainan DARES). It was compiled for Malaysian growers attending his course in Shah Alam on 9 December 2026.

The app is available in **English, 简体中文, 繁體中文 and Bahasa Melayu**. Choose a language from the header; the choice is remembered on that device.

## What's inside

| Tab | Contents |
|---|---|
| Overview | Profile and career timeline, 1998–2026 |
| Core principles | 13 principles from his papers and interviews (fertilize by the soil, disease triangle, microbes as the "second seed", pH as the fastest lever, and more) |
| Field evidence | Trial charts: melon, bitter gourd, nematodes, root rot, salt remediation, rice rotation; an organic farm case study |
| Soil test checker | Enter a lab report (EC, pH, OM, P, K, Ca, Mg) and get a prioritized prescription, including his EC-based base-fertilizer rule |
| Symptom guide | 14 nutrient disorders and root problems: what they look like, causes, and fixes with doses |
| Recovery playbook | Nine steps from diagnosis to monitoring |
| Liquid fertilizer | His fermented High-N / High-P / High-K recipes, a drum-size calculator, and a recipe builder for swapping or leaving out ingredients |
| Works library | 41 papers, handbooks and articles with key findings |
| Glossary | 46 terms explained plainly |
| Sources | Every source used |
| Get microbes | Where to look for mycorrhizal fungi, PSB and *Bacillus* products in Malaysia (sourcing research, not Dr. Huang's recommendations) |

Yields and rates are shown per **acre** (converted from the papers' per-0.1-hectare figures).

## Install and offline use

The app is a Progressive Web App. Open it once while online and it saves itself on the device, including the fonts it uses; after that it opens with no connection.

- **iPhone / iPad (Safari):** Share → **Add to Home Screen**.
- **Android (Chrome):** menu → **Install app** (or **Add to Home screen**).
- **Desktop (Chrome / Edge):** the install icon in the address bar.

When a new version is published, the app shows "A new version is available" with an **Update** button.

## Using it

Open `index.html` in any modern browser; no build step or server is needed. Fonts load from Google Fonts when online and fall back to system fonts offline.

To publish with GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Repository layout

```
src/app.html            Editing source of the app (all HTML, CSS and JS). Edit this file.
index.html              Generated standalone app (do not edit by hand)
manifest.webmanifest    Generated PWA manifest
sw.js                   Generated service worker
icons/                  App icons (generated by tools/make_icons.py, committed)
tools/build_all.py      One command that runs every build step in order
tools/make_index.py     Wraps src/app.html into index.html and adds the PWA snippet
tools/pwa_snippet.html  Service-worker registration and update message
tools/make_pwa.py       Writes manifest.webmanifest and sw.js
tools/script_maps.py    Embeds Simplified/Traditional conversion maps into src/app.html
tools/make_icons.py     Draws the app icons
i18n/                   Translation sources and tooling
  RULES.md              Translation rules and terminology table
  src.json, chunkN.json             English strings, by batch
  zh-Hans.chunkN.json, ms.chunkN.json   Translations, by batch (Traditional is generated)
  build.py              Merges every batch, generates Traditional Chinese, validates, embeds
  extract.js, extract2.js           Collect every visible string from the page (Playwright)
```

## Making a change

1. Edit `src/app.html`.
2. If you changed or added visible text, find the new strings with
   `node i18n/extract.js $PWD/src/app.html $PWD/i18n/keys.json` and
   `node i18n/extract2.js $PWD/src/app.html $PWD/i18n/keys.json`,
   then add a new batch `i18n/chunkN.json` (English) with matching
   `i18n/zh-Hans.chunkN.json` and `i18n/ms.chunkN.json`, following `i18n/RULES.md`.
   Batches are picked up automatically; a later batch overrides an earlier one with the same English text.
3. Run **`python3 tools/build_all.py`**. It runs, in order: `i18n/build.py` → `tools/script_maps.py` →
   `tools/make_index.py` → `tools/make_pwa.py`, and stops on the first error (for example a missing translation).
4. Commit `src/`, `index.html`, `sw.js`, `manifest.webmanifest`, `icons/` and `i18n/`, and push.

The build is deterministic: rebuilding without changes produces identical files, so installed apps only
see "A new version is available" when something really changed. Requires Python 3 with `opencc` and `Pillow`;
the extract scripts need Node with Playwright.

### How translation works

The page keeps its English text as written. A small runtime layer finds each piece of visible text, replaces
numbers with placeholders (`{0}`, `{1}`…), and looks up the translation, so dynamic text such as the soil
checker's prescriptions is translated too. Only the parts of the page that change are re-translated.
Traditional Chinese is converted from Simplified Chinese with Taiwan-standard characters, with a few
Taiwan-usage corrections in `i18n/build.py` (`TW_TERMS`).

Each Chinese mode shows one script only: Simplified mode converts any Traditional characters (for example
original paper titles) to Simplified, and Traditional mode does the reverse. English and Malay hide Chinese
labels everywhere except the Works library and Sources tabs, which keep the original titles.

## Notes and limits

- Content is drawn from Dr. Huang's published papers, Tainan DARES handbooks and newsletters, and interviews in Harvest Farm Magazine (豐年) and NewsMarket. Points that are the compiler's interpretation are marked in the app.
- The "Get microbes" tab is independent sourcing research for Malaysia; product availability was not confirmed with suppliers.
- Translations were produced with AI assistance and checked automatically for completeness; a native-speaker review is recommended, especially for Malay.
- This is not an official publication of Tainan DARES or the Ministry of Agriculture, Taiwan.
